HAYATIMIZ OYUN - BAT DOSYALARI ACIKLAMA

Bu pakette 2 adet BAT dosyasi vardir.

1) 01-siteyi-temizle-git-ve-bat-haric.bat
- Proje klasorunde calistirilir.
- .git klasorunu silmez.
- .bat dosyalarini silmez.
- Diger tum site dosyalarini temizler.
- Temizleme bittikten sonra yeni ZIP icerigi proje klasorune cikarilir.

2) 02-githuba-otomatik-gonder.bat
- GitHub remote adresini ayarlar.
- Dosyalari git add ile ekler.
- Commit olusturur.
- GitHub'a force push yapar.
- Repo: https://github.com/hayatimizoyunyoutube/HayatimizOyunYoutubeArsivi.git

ONEMLI:
- .env, sifre, token, Supabase service role key GitHub'a gonderilmez.
- Gizli bilgiler sadece Vercel Environment Variables icinde tutulur.
- Temiz kurulum sirasinda .git klasoru korunur.
