HAYATIMIZ OYUN - MOBILDEN GITHUB'A YUKLEME REHBERI

ONEMLI:
- .bat dosyalari telefonda calismaz. BAT Windows icindir.
- Telefondan yukleme icin GitHub web sitesi veya GitHub mobil uygulamasi kullanilir.
- Cok dosyali projelerde mobil yukleme zor olabilir. En guvenli yontem bilgisayardan 02-githuba-otomatik-gonder.bat kullanmaktir.

MOBILDEN YUKLEME:
1. ZIP dosyasini telefona indir.
2. ZIP'i dosya yoneticisi ile cikart.
3. github.com sitesine giris yap.
4. Repo: hayatimizoyunyoutube/HayatimizOyunYoutubeArsivi
5. Add file > Upload files sec.
6. ZIP icindeki dosyalari sec.
7. Commit message yaz: v2.1.4.3 ui assets bat update
8. Commit changes de.
9. Vercel uygulamasina veya siteye gir.
10. Deployments > Redeploy > Clear Build Cache yap.

UYARI:
- Vercel Environment Variables ve Supabase gizli keyleri GitHub'a yazilmaz.
- .env dosyasi varsa GitHub'a gonderme.
