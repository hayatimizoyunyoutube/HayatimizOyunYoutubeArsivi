# v2.1.3 Fix 3 - Yetki Yönetimi + Global Bakım

## Eklenenler
- Bakım modu artık sadece localStorage değil, Supabase `public.site_runtime_config` tablosundan global okunur.
- Giriş yapmayan ziyaretçiler bakım modu açıkken animasyonlu bakım ekranını görür.
- Admin paneline Kullanıcı Yetkileri eklendi.
- Kullanıcıyı admin yapma, kullanıcıya düşürme, banlama, ban kaldırma ve silme eklendi.
- Supabase Table Editor üzerinden manuel yetki verme desteklendi.

## Supabase’ten yetkili yapma
`public.site_users` tablosunda kullanıcının `role` değerini `admin`, `is_active` değerini `true` yap. Kullanıcı çıkış/giriş yapınca admin paneli görünür.

SQL örneği:
```sql
update public.site_users
set role='admin', is_active=true, banned_at=null, ban_reason=null, updated_at=now()
where email='KULLANICI_MAILI';
```
