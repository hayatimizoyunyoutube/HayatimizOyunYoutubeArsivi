# Hayatımız Oyun v2.1.3 Fix 5

Bu sürüm kullanıcı yetkileri, bakım modu ve yönetim paneli butonları için hazırlanmıştır.

## Düzeltilenler
- Yönetim panelindeki pasif görünen butonlara gerçek işlem bağlandı.
- Bakım modu Supabase `site_runtime_config` tablosundan global okunur.
- Giriş yapmayan ziyaretçiler ve normal kullanıcılar bakımdayken siteyi göremez.
- `admin` rol adı kaldırıldı; eski `admin` kayıtları `yonetici` olarak okunur.
- Yeni roller: `kurucu`, `yonetici`, `moderator`, `editor`, `user`, `banned`.
- Kurucu/Yönetici kullanıcı yetkisi verebilir, ban kaldırabilir, banlayabilir ve silebilir.
- Supabase role değişikliği sonrası kullanıcı girişte `session-refresh` ile güncellenir.

## Supabase Manuel Kurucu Yetkisi
```sql
update public.site_users
set role = 'kurucu', is_active = true, banned_at = null, ban_reason = null, updated_at = now()
where email = 'SENIN_MAIL_ADRESIN';
```

## Supabase Manuel Yönetici Yetkisi
```sql
update public.site_users
set role = 'yonetici', is_active = true, banned_at = null, ban_reason = null, updated_at = now()
where email = 'SENIN_MAIL_ADRESIN';
```

## Bakım Modunu SQL ile Açma
```sql
insert into public.site_runtime_config (key, value, updated_at)
values ('maintenance_mode', '{"enabled":true,"message":"Hayatımız Oyun kısa süreli bakımda."}'::jsonb, now())
on conflict (key) do update set value = excluded.value, updated_at = now();
notify pgrst, 'reload schema';
```
