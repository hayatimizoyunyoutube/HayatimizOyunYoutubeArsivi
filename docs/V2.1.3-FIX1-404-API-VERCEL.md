# Hayatımız Oyun v2.1.3 Fix 1 — Vercel 404 / API Route Fix

Bu fix, Vercel üzerinde görülen `404: NOT_FOUND` ve kayıt/giriş isteklerinde yanlış API yoluna gitme sorununu düzeltir.

## Değişiklikler

- Frontend API çağrısı `/api/index?action=...` yerine `/api?action=...` olarak düzeltildi.
- `vercel.json` API route'larını SPA yönlendirmesinden ayıracak şekilde güncellendi.
- `/api`, `/api/health`, `/api/register`, `/api/login`, `/api/admin-login` gibi yollar tek `api/index.js` fonksiyonuna yönlendirildi.
- API handler artık hem query string hem de path üzerinden action okuyabilir.
- Supabase kullanıcı kayıt sistemi korunur.
- Vercel Hobby uyumu korunur: sadece 1 serverless function kullanılır.

## Önemli güvenlik notu

`SUPABASE_SERVICE_ROLE_KEY` ve `ADMIN_PASSWORD` herkese açık yerde paylaşılmamalıdır. Paylaşıldıysa Supabase tarafında service role key yenilenmeli ve Vercel Environment Variables güncellenmelidir.
