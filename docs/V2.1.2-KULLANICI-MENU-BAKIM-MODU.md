# v2.1.2 Kullanıcı Menüleri + Bakım Modu

## Amaç

Kullanıcı tarafında görünmemesi gereken yönetim/test/ENV alanları ana kategori menüsünden çıkarıldı. Bu alanlar yönetim panelinde sekme olarak kaldı.

## Kullanıcı ana kategorileri

- Ana Sayfa
- Popüler
- Tamamlanan
- Devam Eden
- Yakında
- Korku
- Aksiyon
- Hikaye Odaklı
- Takvim
- Koleksiyonlar

## Gizli/yönetim alanları

- Test Merkezi
- Hata Raporları
- API Durumu
- AI Öneriler
- Bildirimler
- Yönetim Paneli

## Bakım Modu

Yönetim Paneli > Bakım Modu sekmesinden açılır/kapanır. Açıkken kullanıcı tarafında bakım ekranı görünür; yönetim paneli erişilebilir kalır.

## Buton davranışı

- Hero butonları kullanıcı sayfalarına gider.
- Yönetim paneli butonları panel içinde sekme değiştirir.
- Göstermelik butonlar artık aksiyon mesajı verir.
