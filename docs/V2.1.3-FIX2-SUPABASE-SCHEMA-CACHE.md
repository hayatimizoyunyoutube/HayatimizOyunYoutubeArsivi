# Hayatımız Oyun v2.1.3 Fix 2 - Supabase Schema Cache ve site_settings Duplicate Fix

Bu fix iki hatayı düzeltir:

1. Supabase SQL Editor içinde görünen `duplicate key value violates unique constraint "site_settings_pkey" DETAIL: Key (id)=(1) already exists` hatası.
2. Kayıt formunda görünen `Could not find the table public.site_users in the schema cache` hatası.

## Ne değişti?

- `supabase/schema.sql` daha güvenli hale getirildi.
- Eski `site_settings` tablosundaki `id` sequence çakışması otomatik düzeltilir.
- `site_settings` verileri artık önce update, yoksa insert mantığıyla yazılır.
- `public.site_users` tablosu ayrıca hotfix dosyasına alındı.
- Supabase/PostgREST cache yenilemesi için `notify pgrst, 'reload schema';` eklendi.

## Supabase tarafında çalıştırılacak sıra

1. Önce:
   `supabase/SUPABASE-HOTFIX-v213-fix2-site-users-cache.sql`

2. Sonra gerekirse ana dosya:
   `supabase/schema.sql`

3. Kayıt ekranını test etmeden önce 20-30 saniye bekle veya Vercel redeploy yap.
