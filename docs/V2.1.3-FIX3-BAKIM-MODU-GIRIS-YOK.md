# Hayatımız Oyun v2.1.3 Fix 3 - Bakım Modu Giriş Yapmayanlara Gösterme

## Düzeltilen ana sorun

Önceki sürümde bakım modu açık olsa bile giriş yapmayan ziyaretçi önce giriş/kayıt ekranını görebiliyordu. Bu fix ile bakım modu en üst önceliğe alındı.

## Yeni davranış

- Bakım modu açıksa ve kullanıcı admin değilse direkt animasyonlu bakım ekranı görünür.
- Giriş yapmamış ziyaretçi bakımdayken ana siteyi, giriş/kayıt ana ekranını ve kategorileri göremez.
- Normal kullanıcı giriş yapsa bile bakım açıkken yine bakım ekranında kalır.
- Sadece admin girişi bakım modunu bypass eder.
- Bakım ekranında Admin Girişi butonu vardır.
- Üst menüde bakımdayken Giriş Yap / Kayıt Ol yerine sadece Admin Girişi gösterilir.

## Test adımları

1. Admin olarak giriş yap.
2. Yönetim Paneli > Bakım Modu sekmesine gir.
3. Bakım Modunu Aç.
4. Çıkış yap veya gizli pencerede siteyi aç.
5. Direkt animasyonlu bakım ekranı görünmeli.
6. Bakım ekranındaki Admin Girişi ile admin hesabına gir.
7. Yönetim Paneli açılmalı.
