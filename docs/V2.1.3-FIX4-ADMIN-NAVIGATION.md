# v2.1.3 Fix 4 - Yönetim Paneli Buton Fix

## Sorun
Yönetim panelinde bir butona basınca panel tekrar Genel Bakış sekmesine dönüyordu. Bunun sebebi admin sekme bilgisinin yalnızca panel component içinde tutulması ve toast/işlem sonrası yeniden render sırasında panelin sıfırlanabilmesiydi.

## Çözüm
- Aktif admin sekmesi App seviyesine taşındı.
- Aktif sekme `hayatimizAdminActive` localStorage anahtarıyla korunur.
- `PageContent` iç component olmaktan çıkarılıp direkt render fonksiyonuna çevrildi.
- Sol menü ve hızlı butonlarda `preventDefault` + `stopPropagation` kullanıldı.
- Özellik Planı, Kullanıcı Yetkileri, Bakım Modu ve diğer admin sekmeleri işlemden sonra yerinde kalır.
