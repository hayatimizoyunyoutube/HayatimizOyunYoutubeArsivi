# Hayatımız Oyun v2.1.3

## Eklenenler
- Kayıt Ol formu artık Vercel API üzerinden Supabase `public.site_users` tablosuna kayıt gönderir.
- Tek API dosyası kullanılır: `api/index.js`. Vercel Hobby serverless function sınırı aşılmaz.
- Admin test şifresi ekrandan kaldırıldı. Admin parolası Vercel `ADMIN_PASSWORD` değişkeninden kontrol edilir.
- Yönetim Paneline `Özellik Planı` eklendi.
- Özellik Planı içinde dört alan var:
  - Eklenen özellikler
  - Siteye gelmesi gereken özellikler
  - Gözden kaçanlar
  - Adminin önerileri
- `schema.sql` güncellendi.

## Supabase Kurulum
Supabase SQL Editor içinde sadece `supabase/schema.sql` dosyasını çalıştır.

Kayıtların düşeceği tablo:
`public.site_users`

## Vercel ENV
Gerekli değişkenler:
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `ADMIN_PASSWORD`

Admin şifresi artık sitede yazmaz.
