v2.1.4 Profil Fotoğrafı Notu

Bu sürüm site_users.avatar_url alanını destekler.
Gerçek Supabase Storage yükleme sistemi için:
1. Supabase Dashboard > Storage > New bucket
2. Bucket adı: profile-photos
3. Public bucket açılabilir veya signed URL sistemi sonraki sürümde eklenebilir.
4. Profil formunda avatar_url alanına görselin public URL'si yazılabilir.

v2.1.5 planında doğrudan dosya yükleme endpoint'i eklenecek.
