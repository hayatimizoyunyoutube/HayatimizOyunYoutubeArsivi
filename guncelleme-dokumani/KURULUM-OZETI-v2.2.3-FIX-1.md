# Kurulum Özeti - v2.2.3 FIX 1

1. Mevcut proje klasöründe `.git` klasörünü koru.
2. Eski proje dosyalarını temizle.
3. Bu ZIP içeriğini proje klasörüne çıkar.
4. `npm install`
5. `npm run build`
6. GitHub'a force push yap.
7. Vercel'de Clear Build Cache + Redeploy yap.
8. Supabase SQL Editor içinde `supabase/schema.sql` dosyasını çalıştır.
