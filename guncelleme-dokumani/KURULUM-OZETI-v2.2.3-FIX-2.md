# Kurulum Özeti - v2.2.3 FIX 2

1. `.git`, `.env` ve BAT dosyalarını koru.
2. Diğer eski proje dosyalarını temizle.
3. Bu ZIP içeriğini proje klasörüne çıkar.
4. `npm install`
5. `npm run build`
6. GitHub'a force push yap.
7. Vercel'de Clear Build Cache ile Redeploy yap.
8. Supabase SQL Editor içinde `supabase/schema.sql` dosyasını çalıştır.
