# Kurulum Özeti - v2.2.0 FIX 9

1. Mevcut proje klasöründe `.git`, `.env` ve BAT dosyalarını koru.
2. Eski proje dosyalarını temizle.
3. Bu ZIP içeriğini proje klasörüne çıkar.
4. `npm install` çalıştır.
5. `npm run build` ile test et.
6. `supabase/schema.sql` dosyasını Supabase SQL Editor içinde çalıştır.
7. GitHub'a force push yap.
8. Vercel'de Clear Build Cache ile Redeploy yap.
