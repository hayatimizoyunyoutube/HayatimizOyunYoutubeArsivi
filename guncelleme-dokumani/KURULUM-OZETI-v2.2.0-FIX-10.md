# Kurulum Özeti - v2.2.0 FIX 10

1. `.git`, `.env` ve BAT dosyalarını koru.
2. Eski proje dosyalarını temizle.
3. Bu ZIP içeriğini proje klasörüne çıkar.
4. `npm install`
5. `npm run build`
6. Yeni `supabase/schema.sql` dosyasını SQL Editor içinde çalıştır.
7. GitHub'a temiz force push yap.
8. Vercel'de Clear Build Cache ile Redeploy yap.
