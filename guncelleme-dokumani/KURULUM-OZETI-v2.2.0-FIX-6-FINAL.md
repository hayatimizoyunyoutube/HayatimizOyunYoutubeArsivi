# Kurulum Özeti - v2.2.0 FIX 6 FINAL

1. `.git`, `.env` ve BAT dosyalarını koru.
2. Diğer eski proje dosyalarını temizle.
3. ZIP içeriğini proje klasörüne çıkar.
4. `npm install` çalıştır.
5. `npm run build` çalıştır.
6. GitHub'a temiz force push yap.
7. Vercel'de Clear Build Cache ile Redeploy yap.
8. Supabase SQL Editor içinde yeni `supabase/schema.sql` dosyasını çalıştır.

Bu pakette Supabase'e `site_calendar_events` tablosu eklenmiştir.
