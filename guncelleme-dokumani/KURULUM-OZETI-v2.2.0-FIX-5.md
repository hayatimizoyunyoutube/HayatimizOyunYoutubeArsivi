# KURULUM ÖZETİ - v2.2.0 FIX 5

1. Mevcut proje klasöründe `.git` klasörünü koru.
2. Eski proje dosyalarını temizle.
3. Bu ZIP içeriğini mevcut proje klasörüne çıkar.
4. `npm install`
5. `npm run build`
6. Gerekirse `.env` ve Vercel environment değerlerini mevcut kurulumdaki gibi koru.
7. Testten sonra GitHub'a force push ve Vercel redeploy yap.
