# Hayatımız Oyun v2.1.4 - Gelişmiş Arşiv + Profesyonel UI

Bu paket v2.1.3 stabil sürümünün üzerine hazırlanmıştır.

## Öne çıkanlar

- Koleksiyonlar üst kategori sekmesi kaldırıldı; ana sayfa daha sade hale getirildi.
- Profesyonel oyuncu arşivi kapağı küçültüldü ve istatistik paneline dönüştürüldü.
- Oyun kartlarına bölüm ilerleme yüzdesi, seri bilgisi, izleme butonu ve yakında kilidi eklendi.
- Alfabetik arşiv şeritleri ve Harfe Git navigasyonu eklendi.
- Admin panelinde eksik kapaklar tek ekranda listelenir.
- RAWG kapak seçim ekranında büyük önizleme kullanılır.
- Güncelleme notları paneline sürüm filtresi, arama, düzenle/sil hazırlık butonları eklendi.
- Bakım moduna tahmini açılış zamanı ve profesyonel loading ekranı eklendi.
- Profil fotoğrafı URL alanı ve Supabase Storage kullanım notu eklendi.

## Kurulum

1. `.git` klasörünü silme.
2. Eski proje dosyalarını temizle.
3. Bu ZIP içeriğini proje klasörüne çıkar.
4. `npm install` ve `npm run build` ile test et.
5. BAT dosyasıyla GitHub'a force push yap.
6. Vercel'de Clear Build Cache ile redeploy yap.
