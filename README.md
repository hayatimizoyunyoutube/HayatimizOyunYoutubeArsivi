# Hayatımız Oyun v2.1.2

Bu paket v2.1.2 oyun ekleme/meta düzenleme ve koleksiyon sistemi paketidir.

## Bu temiz paket içinde yapılan düzenleme
- `gelecek-guncelleme-ozellikleri-ve-resimler/` içinde yalnızca `PLANLANANLAR/` ve `TAMAMLANANLAR/` ana klasörleri bırakıldı.
- Eski dağınık `v2.x-planlananlar`, `v2.x-tamamlananlar` klasörleri kaldırıldı.
- Görseller artık ilgili ana klasörlerin içinde `gorseller/vX.X.X/` altında tutuluyor.
- Supabase klasörü sadeleştirildi.
- Normal kurulumda sadece `supabase/schema.sql` ve gerekirse `supabase/YETKI-ORNEK-SQL-v212.sql` kullanılır.
- Ek SQL dosyaları `supabase/opsiyonel/` içine taşındı.

Kurulum için `KURULUM-KOMUTLARI.txt` dosyasını takip et.
