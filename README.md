# Hayatımız Oyun v2.1.4

Otomatik Uygulama Merkezi eklendi. Hazır özellikler Yönetim Paneli > Özellik Planı içinden **Siteye Uygula** ile aktif edilir.

Örnek: “Oyunlar sekmesine Oyun Ekle butonu ekle” maddesini uygula, sonra Yönetim Paneli > Oyunlar içinde **+ Oyun Ekle** butonu görünür ve kayıtlar Supabase `games` tablosuna gider.

Kurulum sırası için `KURULUM-KOMUTLARI.txt` dosyasını oku.
