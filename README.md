# Hayatımız Oyun - Temiz Paket

Bu paket gereksiz eski sürüm klasörleri, eski görseller, dist çıktısı ve dağınık dokümanlar temizlenerek hazırlanmıştır.

## Kalan ana dosyalar

- `src/` site kaynak kodları
- `api/` Vercel API dosyası
- `public/` sadece kullanılan logo, kapak, data ve Vercel fallback dosyaları
- `supabase/schema.sql` güncel Supabase kurulumu
- `TAMAMLANAN VERSİYONLAR.md` eski tamamlanan sürümlerin tek dosyalık arşivi
- `GELECEK GÜNCELLEMELER.md` sadece güncel gelecek plan
- `01-siteyi-temizle-git-ve-bat-haric.bat`
- `02-githuba-otomatik-gonder.bat`

## Vercel ayarları

- Framework Preset: Vite
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`
- Root Directory: boş
