# v2.1.1 - Takvim, Güncelleme Notları ve Bakım Modu

## Durum
Tamamlandı.

## Eklenenler
- Yayın takvimi Supabase `site_calendar_events` tablosuna bağlandı.
- Takvim kayıt ekleme/silme işlemleri Supabase ile senkron çalışacak hale getirildi.
- Güncelleme notları Supabase `site_update_notes` tablosundan okunup yazılacak hale getirildi.
- Not ekleme/silme işlemleri owner/admin token ile güvenli hale getirildi.
- Bakım modu Supabase `site_runtime_config.maintenance_mode` kaydından okunup yazılacak hale getirildi.
- Admin bypass korundu; bakım modu açıkken public kullanıcı bakım ekranı görür, admin siteyi görür.
- API/ENV hata verirse local güvenli mod korunur.
- Güncelleme notları, status ve versiyon bilgisi v2.1.1 olarak güncellendi.

## Schema
`supabase/schema.sql` güncellendi ve gereklidir.

- `DROP TABLE` yok.
- Mevcut verileri silmez.
- Bakım modu mevcut değeri korunur; schema çalışınca otomatik sıfırlanmaz.
