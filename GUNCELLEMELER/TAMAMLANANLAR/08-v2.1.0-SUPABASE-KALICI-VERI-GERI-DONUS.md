# v2.1.0 - Supabase Kalıcı Veri Geri Dönüş

## Durum
Tamamlandı.

## Eklenenler
- Local stabil sistem bozulmadan Supabase kalıcı oyun verisi geri eklendi.
- Oyun listeleme API üzerinden Supabase `games` tablosundan okunabilir hale getirildi.
- Oyun ekle, düzenle, tekil silme ve tüm oyunları silme işlemleri Supabase ile senkron çalışacak hale getirildi.
- API/ENV hata verirse site local güvenli moda düşer ve boş/siyah ekran oluşmaz.
- Giriş/kayıt akışı Supabase API denenip hata durumunda local güvenli moda düşecek şekilde güçlendirildi.
- Admin panelde Supabase yenileme butonu ve veri durumu göstergesi eklendi.
- Kalıcı oyun verisi için API/schema uyumluluk kolonları eklendi.

## Korunanlar
- Boş/siyah ekran koruması kaldırılmadı.
- Kayıt ol / giriş yap korundu.
- Bakım modu yetki koruması korundu.
- Eski ana sayfa, oyun arşivi, koleksiyonlar, RAWG/Steam ve YouTube playlist panelleri korundu.

## Schema
`schema.sql` güncellendi ve gereklidir. Sıfırlamaz; `DROP TABLE` yoktur, mevcut verileri silmez.
