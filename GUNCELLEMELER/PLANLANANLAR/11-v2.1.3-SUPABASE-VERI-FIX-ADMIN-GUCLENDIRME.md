# v2.1.3 - Supabase Veri Fix ve Admin Güçlendirme

## Amaç
v2.1.2 public stabil tabanı bozmadan Supabase veri eşitleme, admin kayıtları ve yetki kontrollerini güçlendirmek.

## Yapılacaklar
1. Supabase oyun/takvim/not/bakım yenileme akışları tek tek kontrol edilecek.
2. Kullanıcı yetki kayıtları daha sağlam hale getirilecek.
3. Admin panel veri durumu daha anlaşılır gösterilecek.
4. Hata çıkarsa yeni sürüm değil, önce fix paketi hazırlanacak.
