HAYATIMIZ OYUN v2.1.4.5 KURULUM SIRASI

BU SÜRÜMDE DÜZELTİLENLER
- Oyun Ekle formunda tür / etiket / kapak çekme güçlendirildi.
- Otomatik Kapak Çek artık Supabase games tablosundaki kapaksız oyunlara kayıt yapmaya çalışır.
- RAWG_API_KEY varsa gerçek kapak ve tür bilgisi denenir. Yoksa güvenli fallback çalışır.
- Akıllı Özellik Ekle önerisinde Düzenle, Sil/Vazgeç, Sadece Uygula, Uygula + Siteyi Yenile akışı var.
- Özellik kartlarına Düzenle ve Sil eklendi.
- Mobil BAT kaldırıldı. Yanlışlık olmaması için sadece 2 BAT dosyası var.
- Kurulum notları bu sürüme göre güncellendi.

1) SUPABASE KURULUMU
- Supabase > SQL Editor aç.
- Eğer tam sıfır istiyorsan önce şunu çalıştır:
  supabase/00-TUM-TABLOLARI-SIFIRLA.sql
- Tam sıfır istemiyorsan bunu çalıştırma; hesapların ve tabloların kalsın.
- Sonra şunu çalıştır:
  supabase/schema.sql

2) KURUCU YETKİSİ
- Siteye kayıt ol.
- Supabase SQL Editor içinde şu dosyadaki örneği kullan:
  supabase/YETKI-ORNEK-SQL-v2145.sql
- Kendi mail adresini yazıp role değerini kurucu yap.

3) TEMİZ KURULUM
- Bilgisayardaki proje klasörüne gir:
  C:\Users\Mevlüt Yeni Pc\Desktop\Youtube Yayın Hazırlıkları\Youtube\Youtube Arşiv Sitesi Güncel\hayatimiz-oyun site vercel
- .git klasörü silinmeyecek.
- İstersen 01-siteyi-temizle-git-ve-bat-haric.bat çalıştır.
- Bu BAT sadece .git ve .bat dosyalarını korur; diğer site dosyalarını siler.

4) ZIP DOSYALARINI ÇIKAR
- Yeni ZIP içindeki dosyaları direkt proje klasörünün içine çıkar.
- İç içe klasör olarak bırakma.
- Proje kökünde package.json, src, api, supabase, index.html görünmeli.

5) GITHUB'A GÖNDER
- 02-githuba-otomatik-gonder.bat çalıştır.
- Ya da PowerShell ile:
  git init
  git branch -M main
  git remote remove origin
  git remote add origin https://github.com/hayatimizoyunyoutube/HayatimizOyunYoutubeArsivi.git
  git add .
  git commit -m "v2.1.4.5 feature cover edit refresh fix"
  git push -f origin main

6) VERCEL
- Vercel > Deployments
- Redeploy seç.
- Clear Build Cache seç.

7) TEST
- Siteye giriş yap.
- Yönetim Paneli > Özellik Planı aç.
- Akıllı Özellik Ekle alanına şunu yaz:
  otomatik kapak resmi çekme
- Sistem “Bunu mu uygulamamı istiyorsunuz?” diye sorar.
- Evet, Uygula + Siteyi Yenile de.
- Yönetim Paneli > Oyunlar içinde Otomatik Kapak Çek görünmeli.
- Oyun Ekle formunda oyun adını yazıp “Oyun adından tür/etiket/kapak çek” de.
