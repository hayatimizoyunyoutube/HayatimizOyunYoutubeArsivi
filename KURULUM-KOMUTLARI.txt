=========================================================
2. SUPABASE ROLLERI
=========================================================

Kullanilacak roller:
- kurucu
- yonetici
- moderator
- editor
- user
- banned

Admin diye rol kullanma. Eski admin rolu site tarafinda yonetici gibi okunur ama yeni sistemde asil rol adi yonetici veya kurucu olmalidir.

Kendini kurucu yapmak icin SQL:

update public.site_users
set role = 'kurucu',
    is_active = true,
    banned_at = null,
    ban_reason = null,
    updated_at = now()
where email = 'MAIL_ADRESINI_BURAYA_YAZ';
