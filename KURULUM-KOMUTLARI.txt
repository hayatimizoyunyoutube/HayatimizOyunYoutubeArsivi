HAYATIMIZ OYUN v2.1.4 KURULUM KOMUTLARI

1) Proje klasöründe .git ve BAT dosyalarını koru.
2) Eski site dosyalarını temizle.
3) Bu ZIP içeriğini proje klasörüne çıkar.
4) Terminal:

npm install
npm run build

5) Supabase gerekiyorsa:
- supabase/schema.sql çalıştır.
- Yetki örneği için supabase/YETKI-ORNEK-SQL-v212.sql dosyasını kendi e-postana göre düzenle.
- Profil fotoğrafı için Supabase Storage içinde profile-photos bucket oluşturabilirsin.

6) GitHub gönderimi:
02-githuba-otomatik-gonder.bat

7) Vercel:
Deployments > Redeploy > Clear Build Cache seç.
