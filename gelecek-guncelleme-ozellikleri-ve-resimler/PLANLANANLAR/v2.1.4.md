# PLANLANANLAR - v2.1.4

v2.1.3 tamamlandıktan sonra sıradaki geliştirme planıdır.

## v2.1.4 için planlanan özellikler

1. İzle butonu gerçek YouTube bölüm listesi / seri detay sayfasına bağlanacak.
2. Seri detay sayfasında sezon, bölüm ve kronolojik zaman çizelgesi görünümü eklenecek.
3. Kapak kırpma sistemi gerçek crop koordinatlarını kaydedip aynı görüntüyü tekrar oluşturabilecek.
4. Profil fotoğrafları `profile-photos` bucket içinde ayrı klasörlerle yönetilecek.
5. Oyun düzenleme geçmişinden tek tık geri alma arayüzü eklenecek.
6. Güncelleme notları Supabase `site_update_notes` tablosundan tamamen kalıcı şekilde listelenecek, düzenlenecek ve silinecek.
7. Eksik meta raporuna toplu meta yenileme / kapak çekme butonu eklenecek.
8. Kullanıcıya özel favori rafları ve cihazlar arası tam senkronizasyon güçlendirilecek.
9. Mobil alt menü ve PWA benzeri hızlı erişim eklenecek.
10. Admin paneline sürüm kontrol ekranı, test raporu ve kurulum kontrol listesi eklenecek.
11. Supabase kurulum dosyaları sadeleştirilecek; eski v2.1.4.x notlarından kalan karışık açıklamalar temizlenecek.
12. Vercel deploy sonrası beyaz ekran / uzun build / env eksikliği için otomatik kontrol rehberi eklenecek.

## Paket kuralları

- Her yeni ZIP içinde sadece yeni sürümün güncel kurulum görselleri bulunacak.
- `TAMAMLANANLAR` ve `PLANLANANLAR` versiyon versiyon korunacak.
- Gizli API key, Supabase service role key veya şifre ZIP içine yazılmayacak.
- Build testi yapılmadan paket verilmemeli.
