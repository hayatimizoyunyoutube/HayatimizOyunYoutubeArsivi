# v2.0.0 Stabil Koruma - Tam Stabil Site Fix

Bu paket, gönderilen `v2.0.0 Temiz Başlangıç` ZIP dosyası incelendikten sonra hazırlanan stabil düzeltme paketidir.

## Düzeltilenler

- `src/main.js` ve `dist/assets/hayatimiz-app-fix64.js` tekrar birebir senkron hale getirildi.
- `window.state` uyumluluğu eklendi; eski patch katmanlarının boş sayfa üretmesi engellendi.
- Yönetim paneli tek stabil katmanda toplandı.
- `Oyun Ekle`, `Mevcut Oyunlar`, `Yayın Takvimi`, `Güncelleme Notları`, `Bakım Modu`, `API/ENV Durumu` sayfaları boş/siyah sayfaya düşmeyecek şekilde yeniden güvene alındı.
- Oyun ekleme/düzenleme formu local fallback + Supabase API ile çalışacak şekilde düzeltildi.
- Yayın takvimi manuel kayıtları local cache içinde korunur, Supabase varsa `site_calendar_events` tablosuna yazılır.
- Güncelleme notları `update-note-save` endpointine bağlandı; eski `update-note-update` uyuşmazlığı API tarafında da alias olarak düzeltildi.
- Bakım modu ayarları schema çalıştırıldığında sıfırlanmayacak şekilde korundu.
- `supabase/schema.sql` eksik tablolarla tamamlandı: `site_users`, `games`, `site_runtime_config`, `site_update_notes`, `site_calendar_events`, `site_features`, `site_admin_planner`, `site_admin_notes`, istek/rapor/bildirim/yedek tabloları.
- Vercel build scripti artık `src` dosyalarını otomatik `dist/assets` içine kopyalıyor; eski dist dosyası kalma riski azaltıldı.
- `vercel.json`, `package.json`, `index.html`, `dist/index.html` sürüm bilgisi `v2.0.0 Stabil Koruma` olarak güncellendi.

## Not

Supabase tarafında bu paketteki `supabase/schema.sql` dosyası SQL Editor içinde çalıştırılmalıdır. Script mevcut kayıtları silmez ve bakım modunu sıfırlamaz.
