Vercel Building uzun kalıyorsa:

1. 1-3 dakika normal olabilir. Hemen iptal etme.
2. 5 dakikadan uzun sürerse Deployment Details > View Logs aç.
3. Log akmıyorsa Cancel yap.
4. Sonra Redeploy > Clear Build Cache seç.
5. Bu sürümde .vercelignore eklendi. Resimler, kurulum görselleri, dokümanlar ve eski preview dosyaları Vercel build içine alınmaz.
6. Framework Preset: Vite
7. Build Command: npm run build
8. Output Directory: dist
9. Install Command: npm install --no-audit --no-fund
10. Environment Variables aynı kalacak; şifre/API key ZIP içinde yok.
