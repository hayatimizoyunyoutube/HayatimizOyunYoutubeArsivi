# VERSION NOTES - v2.1.4

## Tamamlananlar

- Ana menüden gereksiz Koleksiyonlar kategorisi kaldırıldı.
- Ana sayfa hero alanı küçültülüp istatistik odaklı profesyonel panele dönüştürüldü.
- Oyun kartları baştan tasarlandı; kapak, başlık, etiketler ve yazılar daha düzenli hale getirildi.
- Oyun kartlarına Sitede İzle / Serileri İzle / Yakında butonları eklendi.
- Bölüm ilerleme yüzdesi ve progress bar eklendi.
- Oyunlar alfabetik harf şeritleriyle gruplandı.
- Harfe Git navigasyonu eklendi.
- Admin paneline eksik kapak kontrol paneli eklendi.
- RAWG seçim kartlarına büyük kapak önizleme eklendi.
- Güncelleme notları paneline arama ve sürüm filtresi eklendi.
- Bakım moduna tahmini açılış zamanı eklendi.
- Bakım ekranı loading göstergesiyle daha profesyonel hale getirildi.
- Profil fotoğrafı URL alanı eklendi.

## Not

Supabase Storage tarafında gerçek dosya yükleme için `profile-photos` bucket kullanılabilir. Bu sürüm profil kaydında `avatar_url` alanını destekler.
